# 🎓 Student Academic Performance Analysis & Course Recommendation System

## 📌 Project Overview
This project analyzes student academic performance to identify key factors affecting grades and recommend suitable courses.

## 🎯 Objectives
- Analyze study hours vs performance
- Understand impact of part-time jobs
- Identify subject-wise strengths & weaknesses
- Build a course recommendation system

## 📊 Tools Used
- Excel (Data Cleaning, Transformation)
- Power BI (Dashboard, Data Modeling)
- DAX (Measures & Calculations)

## 🧹 Data Cleaning Steps
- Removed duplicates
- Handled missing values
- Trimmed spaces & standardized text
- Split multi-value columns
- Assigned correct data types

## 🏗 Data Model
- Star Schema
- Fact Tables: Student, Course
- Dimension Tables: Course, Preference
- Bridge Table for many-to-many relationships

## 📈 Key Insights
- Majority students are medium performers (~63%)
- Study hours (5–8 hrs) give best results
- Part-time jobs slightly reduce performance
- Subject difficulty is balanced

## 🤖 Course Recommendation Logic
- Based on:
  - Average Marks
  - Student Preferences
  - Course Cutoff Marks

## 📌 Conclusion
The system shows stable academic performance but highlights the need to improve high achievers and support low performers.
